# Product Overview

Wallhaven Downloader is a PyQt5-based desktop application for batch downloading wallpapers from Wallhaven.cc. The application features a modern Apple-style liquid glass UI with advanced visual effects, multi-threading capabilities, and comprehensive user experience enhancements.

## Key Features

- **Multi-mode Downloads**: Latest wallpapers, category-based downloads, keyword search
- **High Performance**: Multi-threaded concurrent downloads (default 10 threads)
- **Modern UI**: Liquid glass effects, blur layers, semi-transparent components
- **Theme System**: Light/dark/auto themes with smooth transitions
- **Internationalization**: Chinese and English language support
- **Accessibility**: WCAG AA compliance, keyboard navigation, screen reader support
- **Cross-platform**: Windows, macOS, Linux support via Briefcase and PyInstaller

## Target Users

Desktop users who want to efficiently download high-quality wallpapers with a premium user experience.
